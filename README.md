# XRD 数据对比工具 (XRD Compare GUI)

用于导入多套 XRD 原始数据（2theta / 强度两列文本），在同一个界面里对比查看，
支持两种作图款式（独立堆叠 / 共享坐标框瀑布图偏移），并可调整图幅尺寸、字体、
线条颜色、坐标轴标题等样式。

基于 Python + PySide6 (Qt) + matplotlib。

## 安装

依赖（PySide6 / matplotlib / numpy）在本机已经装好，直接运行即可；如果在别的
电脑上用，先装依赖：

```powershell
cd xrd_compare_gui
py -m pip install -r requirements.txt
```

## 运行

```powershell
py main.py
```

可先生成几套合成的样例数据试用（4 套模拟 XRD 图谱，峰位/峰形各不相同）：

```powershell
py scripts\make_sample_data.py
```

生成的数据在 `sample_data/`，在程序里点"导入数据…"选中这几个 `.txt` 文件即可。

## 使用说明

### 数据文件格式

文本文件里每一行是 `2theta<空格或制表符>强度`，允许有表头/注释行（只要那一行
解析不出两个数字就会被自动跳过），例如：

```
?
10.0     12
10.01    14
10.02    11
```

导入时会自动按 2theta 从小到大排序。支持 `.txt / .dat / .csv / .xy`，可一次
选择多个文件批量导入。

### 左侧"数据管理"面板（可折叠）

- **导入数据…**：选择一个或多个文件批量导入。
- **删除**：删掉当前选中的数据。
- **↑ / ↓**：调整数据顺序（会影响堆叠图的上下顺序、瀑布图的偏移顺序）。
- 每一行前面的勾选框控制该数据是否显示；小色块点击后可改颜色。
- 选中某一行后，下方"数据属性编辑"里可以改名称、线宽、Y 方向额外偏移
  （在自动堆叠/偏移之外再手动微调这一条曲线）、强度缩放倍数。

点击工具栏里的面板图标可以把"数据管理""绘图设置"这两个面板收起/展开
（Qt 停靠面板，也可以拖到窗口外变成浮动窗口）。

### 中间绘图区

- 顶部是 matplotlib 自带的导航工具条：可以缩放、平移，工具条最右边的保存
  图标可以另存为 matplotlib 支持的各种格式（背景是不透明白色）。
- 工具条最右侧还有一个 **"导出图片…"** 按钮，专门用于导出到 Illustrator 等
  软件里继续排版：可选 PNG / TIFF / SVG 三种格式，导出时背景固定是**透明**的
  （屏幕上的绘图区仍然是白底，只有导出的文件背景透明，方便直接叠加到别的
  版面上）；SVG 是矢量格式，线条在 Illustrator 里可以直接编辑。
- 两种作图款式（在"绘图设置"面板的"作图款式"里切换）：
  - **堆叠图 Stack**：每套数据各自拥有独立的 X/Y 坐标轴，纵向平行拼接在一起，
    互不干扰（类似 OriginLab 的 Stack 图），每个子图右上角标注数据名称（可以
    双击编辑、也可以直接用鼠标拖动到任意位置，见下方"直接在图上双击调整"）。
  - **瀑布图 Waterfall**：所有数据共用同一个 X 轴、同一个坐标框，每套数据的
    Y 值依次叠加一个固定偏移量，从而在纵向上排得很紧凑，方便直接对照峰的
    位置和形状（Y 轴数值本身不重要，因此隐藏了 Y 轴刻度）。

### 右侧"绘图设置"面板（可折叠，与数据管理面板同一侧、可切换标签页）

- **界面主题**：白色 / 黑色 / 黄色 / 绿色，改变的是整个 GUI（面板、按钮、
  列表背景等）的配色；工具栏和绘图区**不受影响**——工具栏背景固定浅色以保证
  图标始终清晰可见，绘图区固定白底黑字（方便截图/打印），跟界面主题无关。
- 图幅宽度/高度（**公制单位，厘米**）、DPI —— 直接决定绘图区大小和导出图片的清晰度。
- 字体（字体族 + 字号）。
- X 轴标题（默认 `2 Theta (degree)`）、Y 轴标题（默认 `Intensity`）。
- **X 轴子刻度阶数**：在主刻度之间画不带数字的子刻度线，用来指示中间位置，
  不用数字标注凑数。选 1 时，每个主刻度间隔的中点画一道，长度是主刻度的一半
  （比如 20 和 30 之间会在 25 画一道）；选 2 时，在此基础上再对半分一次，画出
  更短的子刻度（比如 20-25 之间会在 22.5 再画一道，25-30 之间在 27.5 画一道）；
  选 3、4 以此类推继续对半分、继续变短。留 0（"不显示"）则完全不画。
- 归一化强度（0-1）：把每套数据的强度各自缩放到 0-1，避免因为曝光时间/
  计数率不同导致没法直接对比峰形，默认开启。
- 瀑布图 Y 偏移量 / 堆叠图间距：分别对应两种模式下的排布密度。
- 显示网格线、显示图例（仅瀑布图）。

所有设置修改后会立刻重新绘图。

### 直接在图上双击 / 拖动调整（类似 Origin / Excel）

- **双击某条曲线** —— 弹出该数据的编辑窗口（名称、颜色、线宽、Y 方向额外
  偏移、强度缩放倍数），跟左侧"数据属性编辑"里的内容一致，不用先去侧边栏
  找到对应的那一条再改。
- **双击堆叠图里的数据名称标注** —— 同样弹出该数据的编辑窗口。
- **拖动堆叠图里的数据名称标注** —— 直接用鼠标按住拖到子图内任意位置（默认
  贴在右上角），松手后位置会记住，之后改字号、换主题等操作都不会把它弹回去。
- **双击 X 轴标题或刻度文字** —— 弹出 X 轴标题设置窗口。
- **双击 Y 轴标题或刻度文字**（瀑布图）/ **双击左侧共用的 Y 轴标题**（堆叠图）
  —— 弹出 Y 轴标题设置窗口。

### 缩放/平移视图会被记住

用顶部导航工具条的放大镜/平移工具调整过某套数据（堆叠图）或整张图（瀑布图）
的显示范围之后，再去调整字号、顺序、颜色等其它设置，视图不会跳回默认的自动
缩放范围——每套数据当前的显示范围会按数据本身记住，图幅/字体等设置修改后
自动应用到重新生成的坐标轴上。

## 自测

无界面自动化测试（导入样例数据、切换两种模式、增删改排序、导出 PNG/TIFF/SVG）：

```powershell
py scripts\smoke_test.py
```

## 打包成独立 exe

```powershell
.\build_exe.ps1
```

会自动安装 PyInstaller（如果还没装）并生成 `dist\XRD_Compare_GUI.exe`，
单文件、双击即可运行，不需要目标电脑装 Python。

## 目录结构

```
xrd_compare_gui/
  main.py                    程序入口
  app/
    models.py                Dataset 数据模型
    data_io.py                XRD 文本文件解析（自动跳过表头、多编码兼容）
    plot_style.py              PlotStyle 全局样式配置 + 默认配色
    plot_canvas.py              两种作图款式（stack / waterfall）的渲染逻辑，绘图区固定白底
    theme.py                     整个 GUI 的配色主题（QSS，不含字体/工具栏，避免乱码和图标问题）
    dialogs.py                    双击图上元素时弹出的编辑窗口（数据 / 坐标轴标题）
    dataset_panel.py             左侧数据管理面板（增删排序编辑）
    style_panel.py                右侧绘图设置面板
    main_window.py                 主窗口，整合以上模块
  scripts/
    make_sample_data.py       生成合成样例数据
    smoke_test.py               无界面端到端自测
  sample_data/               合成样例 XRD 数据
  build_exe.ps1              打包 exe 脚本
  requirements.txt
```
